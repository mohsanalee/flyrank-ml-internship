### Main Story

SecureScan AI is an AI-powered security copilot that performs static application security analysis on source code and returns security findings, risk information, explanations, and remediation guidance.

The system follows this general flow:

**User → Frontend → Backend/API → AI Analysis Engine → Results & Reports → Data & Storage → Actionable Insights**

- React-based frontend
- Tailwind-based interface styling
- Python/FastAPI backend
- Static source-code analysis

# 3. Identity Kit

## Typography

### Heading Font

**Space Grotesk**

Used for:

- Main headings
- Section headings
- Project titles
- Important statements

### Body Font

**Inter**

Used for:

- Paragraphs
- Descriptions
- Supporting information
- Navigation
- Labels

Both fonts are free and provide a clean technical appearance.

---

## Color Palette

| Role | Color | Hex |
|---|---|---|
| Main / Primary | Charcoal Black | `#111111` |
| Near-black Text | Deep Charcoal | `#171717` |
| Near-white Background | Soft Off-White | `#F7F7F5` |
| Accent | Muted Green | `#4F8A72` |

The palette is intentionally restrained so that the projects, screenshots, and evidence remain the loudest elements of the portfolio.

# 5. Image Curation Rules

## Real Project Evidence

Real screenshots are used for the SecureScan AI project because they provide direct evidence of the actual product.

The screenshots should remain:

- Clean
- Cropped
- Legible
- Unstretched
- Free from unnecessary desktop or browser UI

The portfolio should not use generated screenshots to represent functionality that was not actually implemented.

## Generated Supporting Visuals

Generated visuals are used only for connective content such as:

- Architecture
- Workflow
- Supporting visual explanation

They should maintain a consistent visual language with the portfolio.

## Personal Image

A real photograph is used for the About section instead of an AI-generated portrait.
